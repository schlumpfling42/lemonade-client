New Spring Boot project:
- Do not write pom.xml or any build file by hand, and do not install Maven or Gradle: generate the project with Spring Initializr. It includes the Maven wrapper (mvnw.cmd and mvnw), which downloads Maven itself on first use, so "mvn: not installed" does not matter.
- ONE setup command (PowerShell, working directory empty = the trusted folder), NAME is the project's folder name, dependencies are comma separated (web, actuator, validation, data-jpa, security, ...; only what was asked). Keep bootVersion=4.2.0: the test imports below are for it.
  curl.exe -sSL "https://start.spring.io/starter.zip?type=maven-project&language=java&bootVersion=4.2.0&groupId=com.example&artifactId=NAME&name=NAME&packageName=com.example.PACKAGE&dependencies=web" -o NAME.zip; Expand-Archive -Path NAME.zip -DestinationPath NAME -Force; Remove-Item NAME.zip
  PACKAGE is NAME without hyphens or dots, lower case (spring-boot-test becomes springboottest, the application class SpringBootTestApplication).
- It creates NAME/pom.xml, NAME/mvnw.cmd, NAME/src/main/java/com/example/PACKAGE/<Name>Application.java and NAME/src/test/java/com/example/PACKAGE/<Name>ApplicationTests.java. Do not plan a change to them unless the request needs one.
- Then plan only what the request adds, as new files: a controller under NAME/src/main/java/com/example/PACKAGE/ and a test under NAME/src/test/java/com/example/PACKAGE/. A controller: package com.example.PACKAGE; imports org.springframework.web.bind.annotation.GetMapping and RestController; @RestController class with @GetMapping("/hello") String hello() returning "Hello".
- A web test in Spring Boot 4 (the packages changed from Boot 3, do NOT use org.springframework.boot.test.autoconfigure.web.servlet): @WebMvcTest(HelloController.class) on the class, imports org.springframework.boot.webmvc.test.autoconfigure.WebMvcTest, org.springframework.beans.factory.annotation.Autowired, org.springframework.test.web.servlet.MockMvc, and static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get, org.springframework.test.web.servlet.result.MockMvcResultMatchers.status and content. The body: @Autowired MockMvc mockMvc; @Test void helloReturnsHello() throws Exception { mockMvc.perform(get("/hello")).andExpect(status().isOk()).andExpect(content().string("Hello")); } (org.junit.jupiter.api.Test).
- Verify command: ".\mvnw.cmd -q test" with the working directory NAME. The first run downloads Maven and the dependencies and can take a few minutes: that is normal.
